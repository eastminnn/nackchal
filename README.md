# nackchal 낙찰

> 겉모습만 보고 값을 매기고, 친구보다 한 푼 더 불러 낙찰받는 **인형 경매장 파티 게임**

**바로 해 보기 → https://nackchal.duckdns.org**

곰·토끼·고양이·강아지 인형이 아늑한 경매장에 둘러앉아요. 라디오, 필름 카메라, 고무 오리처럼 어딘가 사연 있어 보이는 물건이 하나씩 올라오면, 겉모습만 보고 얼마짜리인지 가늠해서 입찰합니다. 낙찰받은 물건의 진짜 가치는 5초 뒤에 공개돼요. 그게 대박인지 쪽박인지는 그때 알게 됩니다.

경매는 진지하게, 장난은 자유롭게. 입찰하다 억울하면 상대에게 토마토를 던지고, 담배 한 대 피우며 표정 관리를 하고, 채팅으로 견제하세요.

## 어떻게 하나요

1. **방에 모여요.** 로그인하고 방을 만들거나 친구의 방에 들어가요. 한 방에 2~4명이 함께하고, 모두 준비하면 방장이 경매를 시작해요.
2. **$100으로 시작해요.** 10라운드 동안 물건이 하나씩 올라오고, 라운드마다 20초 동안 공개 호가 경매가 열려요. 첫 입찰은 $5부터, 이후에는 현재가에 +$1·+$5·+$10을 불러요. 마감 3초 전에 누가 입찰하면 3초가 다시 늘어나요(라운드당 최대 15초).
3. **겉모습은 힌트일 뿐이에요.** 물건은 일반·레어·에픽·전설 등급이 있고, 겉모습이 암시하는 등급은 70%만 맞아요. 전설 물건은 $400까지도 나와요.
4. **낙찰 5초 뒤, 진짜 가치 공개.** 낙찰가는 바로 빠지고, 공개된 실제 가치만큼 돌려받아요. 그 차이가 그 라운드의 손익이에요.
5. **마지막에 돈이 가장 많으면 승리.** 10라운드가 끝나면 남은 돈으로 순위를 매기고, 1등 10캐시, 2등 5캐시, 나머지 2캐시를 계정에 받아요. 동점이면 같은 순위예요. 중간에 나가면 순위와 보상에서 빠져요.

## 장난은 이렇게

| 장난 | 방법 |
| --- | --- |
| 🍅 토마토 · 🥫 깡통 | 받은 캐시로 상점에서 사서 게임 중 친구 캐릭터에게 던져요. 한 판에 3개까지, 같은 친구에게는 5초 간격이에요. 토마토는 얼굴에 철퍽, 깡통은 통! |
| 🖕 · 🚬 모션 | 무료예요. 버튼 하나로 캐릭터가 가운뎃손가락을 들거나 담배를 피워요. 방 안 모두에게 보여요. |
| 💬 채팅 | 언제든 같은 방에 한마디. 캐릭터 머리 위에 말풍선으로도 떠요. |

장난은 화면 연출뿐이라 입찰, 돈, 순위에는 아무 영향이 없어요.

## 이렇게 만들었어요

| 영역 | 기술 |
| --- | --- |
| 화면 | React, TypeScript, Vite, Three.js(React Three Fiber), Zod |
| 서버 | Java 21, Spring Boot 4, Spring Security(JWT 쿠키), 네이티브 WebSocket, JPA, Flyway |
| 데이터 | PostgreSQL 18 |
| 운영 | Docker Compose, Nginx, Caddy(HTTPS), Oracle Cloud, GitHub Actions(CI·자동 배포) |

- **서버가 모든 판정을 해요.** 입찰 순서, 마감 시각, 숨은 가치, 정산은 서버만 알고 결정해요. 화면은 서버가 보낸 상태를 그릴 뿐이에요.
- **실시간 방과 영구 기록을 나눴어요.** 방, 채팅, 진행 중인 경매는 서버 메모리에서 빠르게 돌고, 계정, 캐시, 게임 결과, 아이템은 PostgreSQL에 트랜잭션으로 남아요.
- **돈은 원장으로 관리해요.** 캐시가 바뀔 때마다 기록이 남고, 같은 판의 보상이나 같은 구매가 두 번 처리되지 않아요.

## 직접 실행해 보기

Docker가 있으면 바로 띄울 수 있어요.

```sh
cp -n .env.example .env
openssl rand -base64 32   # 출력값을 .env의 JWT_SECRET= 뒤에 붙여 넣어요
docker compose up -d --build --wait
```

http://127.0.0.1:18000 에서 가입하고 로그인하면 돼요. 브라우저 창 두 개(하나는 시크릿 창)로 계정 두 개를 만들면 혼자서도 경매를 시작할 수 있어요. 개발 서버 실행과 검증 명령은 [운영·배포 안내](deploy/README.md#로컬에서-전체-실행)에 있어요.

```text
├── frontend/                # 화면 (React·Three.js)          → frontend/README.md
├── backend/                 # 서버 (Spring Boot·PostgreSQL)  → backend/README.md

└── docker-compose.prod.yml  # 운영 추가분 (Caddy HTTPS)
```
